Chicago Data Project

A data analysis and SQL project based on datasets from the City of Chicago Data Portal. The project demonstrates how to work with real-world data, perform data analysis with Python, and store and query structured data using a relational database.

📌 Project Overview

This project explores Chicago datasets through a combination of Python, Jupyter Notebook, SQL, and SQLite.

The main objectives are to:

-Work with real-world Chicago datasets
-Explore and understand the data
-Perform data cleaning and preparation
-Load structured data into a database
-Write SQL queries to extract useful information
-Analyze the results using Python
-Practice database and data analysis concepts
